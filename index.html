운영 기준

1. 고객 등록 → Request ID 생성 → 대표 토큰 승인 → 계약/입금 → 실행 유닛 → PO 적재 → 도메인/DNS/GitHub 연결 순서로 사용합니다.

2. 도메인은 고객 명의가 원칙이며, 회사는 DNS·GitHub 연결만 관리합니다.

3. 토큰 승인 전 본사 실행팀 작업 금지.

4. 모든 작업은 로그에 자동 기록됩니다.
